# Python Voice Assistant 🎙️

## About the Project

Hello! This is my Python Voice Assistant project, which I developed as part of my Python Programming Internship at Oasis Infobyte.

The main idea behind this project was to create a simple voice assistant that can listen to voice commands and perform different tasks. Instead of typing every command, users can simply speak to the assistant and get a response.

While working on this project, I got practical experience with Python libraries, speech recognition, text-to-speech conversion, and basic automation.

## What Can It Do?

I have added several useful features to make the assistant interactive:

- **Voice Recognition:** Listens to the user's commands through a microphone.
- **Voice Responses:** Responds to users using text-to-speech.
- **Greeting:** Greets the user according to the current time of day.
- **Time and Date:** Provides the current time and date.
- **Basic Conversation:** Responds to simple commands like Hello, How are you, and Thank you.
- **Calculator:** Solves basic mathematical calculations through voice commands.
- **Google Search:** Opens Google search results based on the user's request.
- **Wikipedia Search:** Opens Wikipedia search results for a given topic.
- **Notes:** Allows users to save notes through voice commands and view them later.
- **Exit:** Closes the assistant when the user says Exit or Stop.

## Technologies and Libraries

For developing this project, I used:

- Python – Main programming language
- SpeechRecognition – To recognize spoken commands
- PyAudio – To access the microphone
- pyttsx3 – To convert text responses into speech
- datetime – To get the current date and time
- webbrowser – To open Google and Wikipedia searches
- ast and operator – To process mathematical expressions

## Getting Started

Follow these steps to run the project on your system.

**1. Clone the repository**

```bash
git clone https://github.com/devbhatt0239-sudo/OIBSIP.git
```

**2. Open the project folder**

```bash
cd OIBSIP
```

**3. Install the required libraries**

```bash
pip install SpeechRecognition pyttsx3 PyAudio
```

**4. Run the project**

```bash
python3 main.py
```

Make sure your microphone is connected and the required microphone permissions are enabled.
